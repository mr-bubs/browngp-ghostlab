# Asset provenance

Retain `vendor/THREE-LICENSE`, `tracks/montreal/CIRCUIT-LICENSE`, `cars/models/MODEL-LICENSE.txt`, and `assets/environment/CREDITS.txt` alongside redistributed assets. The model's source and adaptation notes are recorded in its license file. Constructor paint is recreated in code and does not change the upstream geometry license. Team names, sponsor names and trademarks remain those of their respective owners; this draft is not an official F1 or team product.

Lap manifests record provider provenance. The 2025 importer uses OpenF1 public timing, car-data and location samples. The approved 2026 normalized sample arrays are preserved. Future source publication should retain all notices and select a project code license separately from third-party asset terms.
